# Шолдала Джекпот 🎰

Статическое PWA-приложение для весёлой жеребьёвки внутри команды.

## Возможности

- добавление фотографий с камеры и из галереи;
- локальное хранение состава на устройстве;
- включение и исключение участников;
- честный выбор через `crypto.getRandomValues()`;
- трёхбарабанная анимация, звук, вибрация и конфетти;
- работа без интернета после первого открытия;
- без сервера, базы данных и загрузки фотографий в облако.

## Локальный запуск

```bash
python3 -m http.server 4173
```

Открыть `http://localhost:4173`.

## Бесплатный деплой

### Cloudflare Pages

Создать Pages-проект из этого репозитория. Build command оставить пустой, output directory — `/`.

### GitHub Pages

В Settings → Pages выбрать `Deploy from a branch`, ветку `main`, каталог `/ (root)`.

Приложение полностью статическое. Переменные окружения не нужны.
